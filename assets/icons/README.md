# TableCraft icon assets

- `elephant-craft.png`: final illustration generated with OpenAI ImageGen.
- `ElephantCraft.icns`: macOS icon with 16–1024 pixel representations.

The visual direction is an ivory-and-black elephant engraving on a coral tile.
See [branding notes](../../docs/branding.md) for provenance and installation tools.

Reference collages, vendor resources, backup icons and generated iconsets remain
local and are excluded from Git. Screenshots in the public documentation use
synthetic SQLite data.
